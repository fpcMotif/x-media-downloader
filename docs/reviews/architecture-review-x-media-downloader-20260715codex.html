The JSX would move, not concentrate. StageZone already carries a twelve-value interface. Deepen action policy instead.

Do not create a generic Outbox module

Sync, Capture, and Cloud Upload differ in retry, authority, alarms, and failure policy. A shared interface would expose those differences.

It has one owner. Keep it as an internal seam of the deep Overlay lifecycle until a second real adapter needs it.

Resolve Cloud Provider model conflict first

CONTEXT.md says the provider record owns destination construction; ADR-0017 permits one orchestrator dispatch. Grilling must sharpen the domain model before architecture work.

Separate spec correction: the Footer reads only cloudSyncEnabled. It can say “local only” while Cloud Upload or Capture mirror sends remote data, and “metadata only” while Capture mirror sends tweet text. ADR-0018 explicitly forbids the latter. Correct the definitive Stage spec before implementing any Footer change.
