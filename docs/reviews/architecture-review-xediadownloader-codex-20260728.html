Problem

Solution

  • leverage: every caller gets proof
  • tests hit one interface

Problem
String joins and legacy aliases leak identity policy into every durable adapter.

Give Sweep a durable receipt

Strong local-substitutable

core/clear/worklist.ts · background/clear-worklist-store.ts · background/transfer-launch-coordinator.ts

Before
sequenceDiagram
  participant W as Worklist
  participant B as Background
  participant R as Transfer Registry
  W->>B: queued row
  B-->>W: reply
  B-)R: detached start
  Note over B,R: worker death loses ownership
After
sequenceDiagram
  participant W as Sweep module
  participant C as Clear ledger
  participant R as Transfer Registry
  W->>W: persist queued receipt
  W->>C: persist exact seed
  C-->>W: seed id
  W->>W: mark seeded
  W->>R: launch intents
  W->>W: boot repair
Problem
Sweep replies before any durable module owns the selected Save Requests.
Solution
A receipt module transfers ownership from Worklist to Clear, then Transfer Registry.
  • locality: one recovery state
  • leverage: boot repairs every crash
  • tests cross the real seam

Problem
Consent, erase, mirror, and export cross shallow modules without one serialized owner.
Solution
One Capture Archive interface commits records, mirror intent, erasure generation, and export segments.
  • locality: consent fixed at intake
  • leverage: erase fences every adapter
  • bounded export memory
