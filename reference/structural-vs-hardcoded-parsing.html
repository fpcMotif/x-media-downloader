Structural vs. Hardcoded Parsing

Quick-reference card. Companion to Lesson 1: The Key Trick.

The two ways to find a site's data

Method Where to look When it's there
Network interception DevTools → Network → Fetch/XHR filter; or a content script patching fetch/XMLHttpRequest.prototype.open Data that loads after first paint — scrolling, pagination, opening a modal
Embedded JSON blob document.querySelectorAll('script[type="application/json"]'), look for one whose text contains your target field names Data present on first load — the "hydration" pattern (server pre-fetches, embeds the result so the client doesn't show a spinner)

The shape-signature walk (pseudocode)

function isTargetShaped(node) {
  return typeof node === 'object'
      && node !== null
      && typeof node.CODE_FIELD === 'string'   // pick 2-3 fields that MUST
      && typeof node.OTHER_FIELD === 'string'  // co-occur on your target,
      && node.OTHER_FIELD !== ''               // and are cheap to check
}

function forEachMatch(json, visit) {
  const walk = (node) => {
    if (Array.isArray(node)) { node.forEach(walk); return }
    if (typeof node !== 'object' || node === null) return
    if (isTargetShaped(node)) visit(node)
    for (const key of Object.keys(node)) walk(node[key])   // ALWAYS keep
  }                                                          // recursing —
  walk(json)                                                 // don't `return`
}                                                              // after a match
Picking a good signature Prefer fields that are required for the site's own UI to render (an id, a username, a URL) over fields that are cosmetic or optional. If the site's own page would break without that field, the site's own developers can't quietly remove it either — which is exactly what makes it a stable anchor.

Real example (this session)

Instagram/Threads post identity: a node is "a post" if it has a non-empty code string (the URL shortcode) and a user.username string. The actual JSON path to reach that node was a different, deeply-nested shape every time — a live capture from this session:

root.require[0][3][0].__bbox.require[0][3][1].__bbox
    .result.data.xdt_api__v1__feed__timeline__connection
    .edges[0].node.media

Nobody should hardcode that path. The shape-signature walk finds the node wherever it lives, on this response or the next redesign's response.

Picking the "best" candidate from an array

Media URLs are usually offered at several resolutions/qualities in an array. Rank by width × height (both default to 0 if missing, so a dimensioned candidate always beats an undimensioned one), first-wins on a tie:

const area = c => (c.width ?? 0) * (c.height ?? 0)
const best = candidates.reduce((a, b) => area(b) > area(a) ? b : a)

DOM-only fallback (when you can't/don't want to touch the network)

  • A rendered <img>'s currentSrc is often the SAME CDN URL family as what's in the JSON — but possibly a different resolution, so its raw basename won't always equal the JSON-detected item's key. Look for a way to normalize across renditions (X forces a canonical quality query param on any twimg URL, regardless of what the DOM happened to render).
  • CDN URL path families often distinguish content types without touching JSON at all (e.g., an avatar path segment vs. a post-content path segment). Useful for a cheap "is this even worth trying to grab" filter before checking identity.
  • <video> elements streamed via MediaSource Extensions have a blob: local URL with zero correlation to the real file — there is no DOM-only trick for video identity. Check for a sibling poster/thumbnail <img> near the player as a fallback; if there isn't one, DOM-only video resolution isn't possible and that's a real constraint, not a shortcut you're missing.

Staying on the right side of personal-use scraping

  • Read-only, your own logged-in session, no bypassing a login/paywall you don't already have legitimate access to.
  • Passive observation of traffic the page already generates beats firing your own extra requests — no added load on the target's servers.
  • Don't redistribute what you collect; personal archival is a different legal posture from republishing.
