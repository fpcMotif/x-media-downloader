# Product

## Register

product

## Users

People browsing X, Instagram, or Threads who want to save post media quickly, at original quality, without sending account data or media URLs to a remote downloader by default.

## Product Purpose

X Media Downloader is a local-first Chrome extension for saving photos, videos, and GIFs the user can already view. Downloads stay local by default. Cloud sync, Capture mirroring, and cloud upload are explicit opt-ins. Success means the user can notice media, download one item or a whole detected set, understand progress, recover from stale state, and keep Downloads organized with minimal permissions.

## Brand Personality

Fast, restrained, trustworthy.

## Anti-references

Do not look like a sketchy downloader site, a marketing landing page, a heavy dashboard, or a noisy browser extension packed with decorative cards. Avoid vague "AI tool" styling, oversized hero treatment, over-rounded panels, washed-out gray text, and controls that obscure page content.

## Design Principles

- Stay close to the user's browsing flow: the in-page controls should feel like precise tools, not a second app layered over the site.
- Make primary actions obvious: download one, download tweet, download all, find new media, and clear monitor must read instantly.
- Keep privacy visible through restraint: local-first, opt-in cloud features, minimal permissions, no telemetry, no dramatic visual treatment.
- Prefer compact confidence over decoration: dense controls are acceptable when spacing, alignment, focus, and hit targets are deliberate.
- Separate safe reset actions from destructive actions: clearing stale UI state must not imply cancelling active downloads or deleting files.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls, keyboard-operable popup controls, visible focus indicators, reduced-motion support, and at least 40px pointer targets in the popup plus 44px targets for injected page controls where space permits.
